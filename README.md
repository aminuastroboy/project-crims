# CRIMS Frontend

A polished Next.js frontend mockup for a Crime Intelligence Management System.

## Included Screens
- Secure login page
- Operational dashboard
- Suspect records list
- Add new suspect form
- Suspect profile view
- Case management page
- Users and roles page

## Stack
- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Lucide React icons

## Run locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Notes
This package is frontend-only and uses static mock data from `lib/data.ts`.
